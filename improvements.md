# AI Workshop - Prompt Optimization

## Original Prompt Issues Identified

1. Hollow flattery - calling AI "very intelligent, smart, highly advanced" adds no value
2. Vague adjectives - "detailed, comprehensive, elaborative" give no real constraints
3. Anxiety framing - "extremely critical, don't miss anything" doesn't improve output
4. Context dump - 30+ technologies listed with no prioritisation
5. 23 deliverables in one request - too broad for quality output

## Optimised Prompt (Phase 1)

You are a senior enterprise solutions architect specialising in AI systems.

### Context
- Organisation: 1500 employees, multinational
- Primary stack: AWS, Kubernetes, Python, Terraform
- Compliance: SOC 2, GDPR required
- Team: 5 engineers, 6-month delivery target

### Task
Design high-level architecture for an enterprise AI chatbot.
Recommend ONE approach per layer with justification.
